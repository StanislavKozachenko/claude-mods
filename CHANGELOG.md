# Changelog

All notable changes to this project will be documented in this file.

Each mod is versioned on its own: entries are headed `[<mod> <version>]` and tagged `<mod>--v<version>`.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and each mod adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
