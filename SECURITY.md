# Security

Mods run inside Claude Code with access to tool calls, files and processes through its plugin API. If you find a way to bypass a mod in this repository, a leak, or behaviour its README does not describe, report it privately through [GitHub security advisories](https://github.com/StanislavKozachenko/claude-mods/security/advisories/new) instead of a public issue.

Guard-style mods are a safety net, not a sandbox: they reduce the chance of an accident, they do not contain a hostile model or a hostile prompt.
